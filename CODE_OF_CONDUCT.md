# Contributor Covenant Code of Conduct

## Unsere Verpflichtung

Als Mitwirkende und Maintainer verpflichten wir uns, eine belästigungsfreie
Umgebung für alle zu schreiben — unabhängig von Alter, Behinderung,
ethnischer Zugehörigkeit, Geschlecht, Identität, Erfahrungsstand,
Nationalität, persönlichem Aussehen, Religion oder sexueller Orientierung.

## Unsere Standards

Beispiele für positives Verhalten:

- Einladende und inklusive Sprache verwenden
- Respektvoller Umgang mit unterschiedlichen Meinungen
- Konstruktive Kritik annehmen
- Fokus auf das Beste für die Community

Beispothe für inakzeptables Verhalten:

- Sexualisierte Sprache oder Bilder
- Trollen, beleidigende/kommentare, persönliche Angriffe
- öffentliche oder private Belästigung
- Veröffentlichung anderer Informationen ohne Erlaubnis

## Durchsetzung

Maintainer können Kommentare, Commits oder Issues entfernen, die nicht
diesem CoC entsprechen. Bei Missbraucht kontaktiere: info@qapdex.com

## Verweis

Dieser CoC basiert auf dem [Contributor Covenant](https://www.contributor-covenant.org), Version 2.1.
